# Adidas Shoes Store 👟

A modern Adidas shoes store website built using HTML, CSS, and JavaScript.

## 🚀 Features

- Responsive Design
- Add To Cart System
- Cart Counter
- Remove Products From Cart
- Product Details Page
- Search Products
- LocalStorage Support
- Modern UI Design
- Men / Women / Kids Sections

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 📂 Pages

- Home Page
- Men Collection
- Women Collection
- Kids Collection
- Product Details
- Cart Page
- Checkout Page

## 🛒 Shopping Cart Features

- Add products to cart
- Prevent duplicate products
- Auto calculate total price
- Save cart using LocalStorage
- Remove items from cart

## 📱 Responsive Design

The website is fully responsive and works on:

- Mobile Phones
- Tablets
- Desktop Screens

## 🎨 UI Design

- Dark Modern Theme
- Smooth Hover Effects
- Responsive Product Cards
- Modern Navigation Bar
